01 / START

快速接入

发起 GET 请求即可获取台词。浏览器页面可以直接使用 fetch；跨域请求已开放。

const response = await fetch("https://arkoto.me/api/v1/quotes/random");
if (!response.ok) throw new Error(`Arkoto: ${response.status}`);
const quote = await response.json();
document.querySelector("#quote").textContent =
  `${quote.content} —— ${quote.operator.name}`;

命令行可以用：

curl 'https://arkoto.me/api/v1/quotes/random'
02 / QUOTES

获取台词

GET/api/v1/quotes/random打开 ↗

每次请求从符合筛选条件的台词中随机取一条。

GET/api/v1/quotes/today打开 ↗

按北京时间选取当天台词。同一天、同一组筛选条件会得到相同的台词；更换日期或数据快照后可能改变。

03 / FILTERS

筛选参数

两个台词接口都接受以下可选查询参数，也可以组合使用：

参数含义示例
operator干员名称或 ID，精确匹配阿米娅
title台词场景名称，精确匹配任命助理
# 随机获取阿米娅的台词
curl --get 'https://arkoto.me/api/v1/quotes/random' \
  --data-urlencode 'operator=阿米娅'

# 每天固定获取阿米娅的「任命助理」台词
curl --get 'https://arkoto.me/api/v1/quotes/today' \
  --data-urlencode 'operator=阿米娅' \
  --data-urlencode 'title=任命助理'

在 JavaScript 中用 URLSearchParams 编码中文参数。没有匹配结果时返回 404。

05 / DISCOVERY

查询干员与场景

GET/api/v1/operators?q=阿米娅&limit=20打开 ↗

按名称搜索干员，返回 { "data": [...] }。q 是可选的名称片段；limit 默认为 50，范围为 1–200，超出范围会被收敛到边界。

GET/api/v1/categories打开 ↗

返回场景名称和各场景台词数量，结构为 { "data": [{ "title": "任命助理", "line_count": 483 }, ...] }。将 title 传给台词接口即可按场景筛选。

GET/api/v1/status打开 ↗

查看台词、干员与立绘数量，以及 imported_at 数据同步时间。

06 / BIRTHDAYS

干员生日与立绘

GET/api/v1/birthdays/today打开 ↗

按北京时间返回当天过生日的干员，以及已有的对应立绘信息。当天无人生日时，成功返回 200 和空的 data 数组。此接口不接受 date 参数。

GET/api/v1/birthdays打开 ↗

查询生日档案。可传 operator 精确匹配干员名称或 ID，或用 date=MM-DD 按月日筛选。两者可以组合；不传参数则返回全部已收录的生日档案。日期必须有效且补足两位，例如 02-29、12-23。

# 查询某位干员的生日与立绘
curl --get 'https://arkoto.me/api/v1/birthdays' \
  --data-urlencode 'operator=阿米娅'

# 获取 12 月 23 日过生日的干员
curl 'https://arkoto.me/api/v1/birthdays?date=12-23'

# 获取今天过生日的干员
curl 'https://arkoto.me/api/v1/birthdays/today'

响应中 date 为今日查询的北京时间 YYYY-MM-DD、指定查询的 MM-DD，或未筛选日期时的 null。timezone 为 Asia/Shanghai；data 每项包含：

字段说明
operator干员 id 与 name
birthdaymonth、day 与基础档案中的 text。未公开或日期不确定时，月、日均为 null，保留原文
illustration与台词接口相同的立绘对象，含 url、source 与 filename；未收录对应立绘时为 null
source本次生日索引对应的游戏档案来源

不确定的生日不会出现在日期筛选与今日生日中。没有匹配干员时返回空数组。不同干员 ID 的异格档案分别展示；不自动合并。imported_at 是生日数据的同步时间，与台词数据同步时间独立。

07 / STORY ARCHIVE

故事留下的画面

GET/api/v1/cg/random打开 ↗

随机返回一张剧情 CG 的图片链接和来源。CG 是独立图库，与干员台词没有一一对应关系。

{
  "data": {
    "type": "story_cg",
    "url": "图片地址",
    "source": "图片来源地址",
    "filename": "图片文件名"
  }
}

图片由第三方来源托管，接口只返回链接与文件名。网页中也可以在首页的“故事留下的画面”区块随机浏览。

08 / NOTES

错误与使用说明

状态码说明
200请求成功
400参数格式无效，例如非整数的 limit、无效的生日日期 invalid_date，或向今日生日传入 date（date_not_allowed）
404找不到符合筛选条件的台词或接口
405请求方法不支持
503服务或数据暂不可用

错误响应通常包含 error，部分还包含 message。客户端应检查 HTTP 状态码。接口支持 GET、HEAD、OPTIONS 和跨域读取。

Arkoto 是非官方玩家项目。引用台词或展示立绘时，请保留来源信息并自行确认相关内容的使用范围。公开接口与第三方图片来源均未提供可用性保证。
